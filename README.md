# Coffee Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes coffee sales data using Microsoft Power BI to identify
sales trends, customer preferences, and product performance.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## 📈 Dashboard Features

- Total Sales Analysis
- Sales by Coffee Type
- Sales by Country
- Monthly Sales Trends
- Product Performance
- Interactive Filters and Slicers

## 📂 Files Included

- `project powerbi.pbix` – Power BI dashboard file
- `index_1.csv` – Dataset used for the analysis
- `Screenshot 2026-09-25 195903.png` – Dashboard preview
